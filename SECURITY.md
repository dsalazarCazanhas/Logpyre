# Security Policy

## Supported Versions

Logpyre is pre-1.0 and under active development. Only the latest commit on `main` is supported — please update before reporting an issue.

## Reporting a Vulnerability

Please **do not** open a public issue for security vulnerabilities.

Report privately via [GitHub Security Advisories](https://github.com/dsalazarCazanhas/Logpyre/security/advisories/new) ("Report a vulnerability" under the repo's Security tab).

This is a solo-maintained project across several repositories, so there's no fixed SLA — reports are triaged and addressed on a best-effort basis. You'll get an acknowledgement once the advisory is reviewed.
